# 一掷千金游戏规则

## 一、游戏目标

玩家从 30 个行李箱中选择 1 个作为自己的箱子，再按照轮次打开其他箱子。每轮结束后，资本家根据剩余箱子的金额进行报价，玩家可以选择接受报价或继续挑战。

最终奖金可能来自：

- 接受资本家报价；
- 坚持到最后并获得自己箱子中的金额；
- 已解锁的金额阶梯组奖励。

> 本游戏为前端演示版本，刷新页面或点击“重新开始”会重置游戏数据。

## 二、基础参数

| 项目 | 规则 |
|---|---:|
| 初始账户余额 | ¥50,000 |
| 每局报名费 | ¥5,000 |
| 行李箱数量 | 30 个 |
| 最高金额 | ¥200,000 |
| 资本家思考时间 | 3 秒 |
| 玩家报价思考时间 | 60 秒 |

点击“支付报名费，开始挑战”后，系统会从账户余额中扣除 ¥5,000。

## 三、公开金额阶梯

30 个金额会在游戏开始时全部公开，但玩家不知道每个金额对应哪个箱子。金额按照以下顺序排列，并分为 5 组，每组 6 个金额：

| 组别 | 金额 | 组奖励 |
|---|---|---:|
| 第 1 组 | ¥1、¥10、¥50、¥100、¥200、¥300 | ¥2,000 |
| 第 2 组 | ¥500、¥800、¥1,000、¥1,200、¥1,500、¥1,800 | ¥1,800 |
| 第 3 组 | ¥2,000、¥2,500、¥3,000、¥3,200、¥3,500、¥3,800 | ¥1,500 |
| 第 4 组 | ¥4,000、¥4,200、¥4,800、¥10,000、¥20,000、¥30,000 | ¥1,200 |
| 第 5 组 | ¥50,000、¥80,000、¥100,000、¥130,000、¥160,000、¥200,000 | ¥1,000 |

5 组奖励合计：

$$
¥2,000 + ¥1,800 + ¥1,500 + ¥1,200 + ¥1,000 = ¥7,500
$$

## 四、选择自己的箱子

报名成功后，玩家先从 30 个箱子中选择 1 个作为自己的箱子：

- 选择后，自己的箱子会显示为 `YOUR CASE`；
- 自己箱子中的金额不会立即公开；
- 自己的箱子不能在普通开箱阶段打开；
- 自己的箱子最终金额会在游戏结束时结算。

选择自己的箱子后，系统会弹层提示当前轮次和本轮可选择的箱子数量。

## 五、开箱轮次

玩家自己的箱子不计入普通开箱数量。其他箱子按照以下 12 轮打开：

| 轮次 | 本轮可打开数量 |
|---:|---:|
| 第 1 轮 | 5 个 |
| 第 2 轮 | 4 个 |
| 第 3 轮 | 4 个 |
| 第 4 轮 | 3 个 |
| 第 5 轮 | 3 个 |
| 第 6 轮 | 3 个 |
| 第 7 轮 | 2 个 |
| 第 8 轮 | 2 个 |
| 第 9 轮 | 1 个 |
| 第 10 轮 | 1 个 |
| 第 11 轮 | 1 个 |
| 第 12 轮 | 1 个 |

合计打开 30 个箱子位置中的 29 个箱子，最后留下玩家自己的箱子进行最终结算。

每轮开始前会弹出提示，例如：

> 第 2 轮：接下来可以选择 4 个箱子。

## 六、金额显示

- 右侧金额阶梯始终保持可见；
- 已经开出的金额会变灰并显示“已开”；
- 已开金额会显示删除线；
- 未开金额保持原有颜色；
- 每 6 个金额使用同一组颜色标识。

## 七、组奖励规则

组奖励不是按照“本轮开了几个箱子”计算，而是按照金额阶梯组计算。

只有当某一组的 6 个金额全部被开出时，该组才会解锁奖励：

1. 系统检查该组的 6 个金额是否全部显示为已开；
2. 条件满足后，立即解锁对应组奖励；
3. 账户余额增加该组奖励；
4. 弹出庆祝弹层显示奖励金额；
5. 点击“庆祝完成，继续”后回到游戏流程。

玩家自己的箱子不属于“已开出金额”。如果玩家自己的箱子属于某一组，则该组在玩家箱子最终打开前无法完成解锁。

## 八、资本家报价

每轮规定数量的箱子全部打开后，资本家会进行报价：

1. 弹出报价窗口；
2. 资本家思考 3 秒；
3. 思考期间 `DEAL` 和 `NO DEAL` 按钮不可点击；
4. 3 秒后显示可接受的报价；
5. 玩家拥有 60 秒思考时间。

报价主要参考：

- 剩余未开箱子的平均金额；
- 已开箱金额的平均水平；
- 当前轮次；
- 剩余金额整体价值。

报价倾向：

- 前 3 轮更加保守，报价偏低；
- 后续轮次根据剩余金额逐步调整；
- 未开箱子的平均金额越高，报价通常越高；
- 已开箱金额整体越高，报价会受到压低；
- 已开出较多低金额时，资本家可能提高报价。

## 九、Deal / No Deal

### Deal

点击 `DEAL · 带走报价`：

- 接受当前资本家报价；
- 报价金额加入账户余额；
- 游戏立即结束；
- 已获得的组奖励保留并计入本局结果。

### No Deal

点击 `NO DEAL · 继续`：

- 拒绝当前报价；
- 关闭报价弹层；
- 进入下一轮提示；
- 继续打开箱子。

## 十、倒计时规则

报价生成后，玩家有 60 秒进行决定：

- 在倒计时内可以点击 `DEAL` 或 `NO DEAL`；
- 倒计时结束后，系统自动执行 `NO DEAL`；
- 自动拒绝报价后，游戏进入下一轮。

## 十一、最终结算

当除玩家箱子外的所有箱子都完成开箱后：

- 游戏结束；
- 打开并显示玩家箱子的金额；
- 加上已解锁的全部组奖励；
- 将玩家箱子金额和组奖励加入账户余额；
- 显示最终结果。

最终带走金额计算方式：

$$
最终带走金额 = 玩家箱子金额 + 已解锁组奖励
$$

## 十二、界面按钮

| 按钮 | 功能 |
|---|---|
| 支付报名费，开始挑战 | 扣除报名费并开始新局 |
| 开始本轮 | 关闭轮次提示并允许选择箱子 |
| 庆祝完成，继续 | 关闭组奖励弹层并继续游戏 |
| DEAL · 带走报价 | 接受资本家报价并结束游戏 |
| NO DEAL · 继续 | 拒绝报价并进入下一轮 |
| 再来一局 | 关闭结算提示，准备下一局 |
| 重新开始 | 清除当前进度并恢复初始余额 |

## 十三、风险提示

- 报名费每局为 ¥5,000；
- 低金额箱子数量较多，打开金额低于报名费的箱子时，玩家可能产生亏损；
- 资本家报价不保证高于报名费；
- 接受报价后不能反悔；
- 拒绝报价后可能获得更高金额，也可能最终获得更低金额；
- 请理性游戏，量力而行。
